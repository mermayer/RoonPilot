Primäre RoonPilot-Firmware

Firmware-Installer

Die primäre ESP32-S3-Firmware wird ausschließlich mit diesem autorisierten Browser-Installer installiert. Factory- und OTA-Abbilder werden nicht als eigenständige Downloads angeboten.

Zwei unabhängige Prozessoren. Im Geräteauswahldialog den Namen vor der Klammer prüfen und für diesen Installer USB JTAG/serial debug unit wählen. Eine Factory-Installation löscht den gesamten ESP32-S3 einschließlich aller Einstellungen. Eine Sicherung der Original-Firmware ist optional und nur dann sinnvoll, wenn später der exakte Auslieferungszustand des Herstellers wiederhergestellt werden können soll.
Nur ESP32-S3 · USB Web Serial

Im Browser installieren

Einen aktuellen Chromium-Desktopbrowser wie Chrome oder Edge verwenden. Vorher alle seriellen Monitore schließen. Firefox und Safari unterstützen diesen Web-Serial-Ablauf nicht.

Eintrag im Geräteauswahldialog

Diese Namen erscheinen im Dialog des Webinstallers selbst. Entscheidend ist jeweils der Name vor der Klammer:

ZielgerätWindowsmacOS
RoonPilot-Hauptprozessor ESP32-S3USB JTAG/serial debug unit (COM…)USB JTAG/serial debug unit (cu.usbmodem…)
RoonPilot-Companion, klassischer ESP32USB serial (COM…)USB serial (cu.wchusbserial…)

Hier die erste Zeile auswählen. Eine vorherige Prüfung im Geräte-Manager, macOS-Systembericht oder mit esptool ist nicht erforderlich. Steht im geöffneten Dialog USB serial, USB abziehen, den USB-C-Stecker am runden RoonPilot-Gerät um 180° drehen und neu verbinden. Der Webinstaller erkennt das Gerät sofort wieder und zeigt USB JTAG/serial debug unit an.

Löschen bei einer Factory-Installation

Vorher ist kein separater Löschvorgang erforderlich. Bietet der Installer Erase device an, dies bei einer Erstinstallation oder vollständigen Wiederherstellung auswählen beziehungsweise bestätigen. Die saubere Installation löscht alle Einstellungen des ESP32-S3, aber nicht den Companion-ESP32. Spätere Onlineupdates unter System → Firmware update benötigen kein Löschen.

Einen aktuellen Chromium-Desktopbrowser mit Web Serial verwenden, beispielsweise Chrome oder Edge. Diese HTTPS-Seite vor dem Verbinden des USB-Gerätes öffnen.

Normale Updates

Direkt durch RoonPilot unter System → Firmware update. Ein OTA-Dateidownload wird nicht angeboten.

Separater klassischer ESP32 · optional

Companion-Sleep-Firmware

Sie gibt gemeinsam verwendete Signale frei, schaltet den ungenutzten DAC-Pfad stumm und versetzt den zweiten ESP32 in Deep Sleep. RoonPilot funktioniert auch ohne sie vollständig.

Die normale Installation erfolgt ebenfalls ohne Python oder Kommandozeile über einen eigenen Webinstaller. Dort muss im Browserdialog USB serial gewählt werden, nicht USB JTAG/serial debug unit.

Browser-Installation

Nur einen aktuellen Chromium-Desktopbrowser wie Chrome oder Edge verwenden. Firefox und Safari unterstützen den benötigten Web-Serial-Ablauf nicht. Vorher alle seriellen Monitore schließen.

Die Factory-Installation löscht den ESP32-S3 vollständig, einschließlich Firmware, WLAN-Zugangsdaten, Roon-Freigabe und Einstellungen. Normale spätere Updates erfolgen am Gerät unter System → Firmware update.

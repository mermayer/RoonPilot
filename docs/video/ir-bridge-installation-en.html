Read all the steps

  1. The optional IR Bridge

    In this guide we will set up the optional RoonPilot IR Bridge. You will see every important click, learn commands from your remote and assign the Bridge to a Roon zone. No programming knowledge is needed. Pause the video whenever you want to follow a step yourself.

  2. RoonPilot also works without a Bridge

    Most importantly, RoonPilot works without this Bridge. Playback, track selection, Live Radio and volume control provided by Roon remain available. You only need the IR Bridge if you also want to control equipment through its infrared remote, such as an amplifier without suitable Roon volume control.

  3. A learning infrared remote control

    RoonPilot sends a control command to the Bridge over Bluetooth, or over Wi-Fi when fallback is configured. The Bridge then transmits the infrared command it learned earlier to your audio equipment. This enables volume, mute and optional power control. The Bridge receiver is used to learn from the original remote.

  4. No audio streaming. No feedback from the amplifier.

    The Bridge does not stream music, replace a Roon Server or act as an audio endpoint. It is not an RME MIDI Bridge or the Companion firmware inside the round device. Ordinary infrared equipment does not report its actual volume or power state back. Play, pause and track changes still go to Roon.

  5. The Bridge is a separate ESP32-S3 board

    For the documented reference unit you need an ESP32-S3-Zero-compatible board, a suitable IR transmitter and an IR receiver for learning. This guide shows an Adafruit High Power IR Emitter and a KY-022 receiver. You also need a USB data cable and the original remote. Check the exact board name, not just its appearance.

  6. Wire with power disconnected – then connect

    Unplug USB before changing any wiring. The transmitter signal connects to GPIO 4, also labelled GP4. The receiver output connects to GPIO 5. Connect the ground terminals to GND. The documented receiver uses 3.3 volts. Follow the module labels, never cable colours alone. Never apply 5 volts to a GPIO.

  7. Power and signal are two different things

    The Adafruit transmitter shown accepts a 3 to 5 volt supply and a 3.3 volt control signal. Usable range also depends on its supply. Beware: a board label saying 5V does not guarantee a USB-powered output. Check your particular board version and module terminals. Do not connect two power sources together indiscriminately. If unsure, have the wiring checked.

  8. The transmitter must reach the audio equipment

    Place the Bridge so its IR transmitter can reach the equipment’s sensor. A closed cabinet door or a covered sensor can prevent commands getting through. The receiver must be accessible to the remote while learning. Keep the antenna area clear and use stable USB power. An enclosure must not shield the transmitter, receiver or antenna.

  9. A factory installation erases the Bridge

    With a new Bridge you can continue straight away. On an existing Bridge, factory installation erases its identity, pairing, Wi-Fi and local profiles. First create a configuration backup under System in RoonPilot. This saves the profile library, but version 2.0.2 does not restore Bluetooth keys. You must pair again afterwards. For routine future updates, use the Bridge update in RoonPilot instead.

  10. Open Chrome or Edge on a computer

    Install using current Chrome or Edge on a computer. Firefox, Safari, iPhone and iPad are not suitable for this USB installer. Later you can use a phone to configure the RoonPilot webpage. Close any program using the serial USB port and use a data cable. A charge-only cable is not enough.

  11. Avoid confusing it with the round RoonPilot

    For installation, connect only this Bridge to the computer. Temporarily disconnect other ESP32 devices from the computer, including the round RoonPilot. Both can show the same USB name. On a factory-new board, hold BOOT while plugging it in and release once the port appears. The Bridge does not need the USB-C connector reversal used for the Companion inside the round device.

  12. Open the dedicated IR Bridge installer page

    Open the official IR Bridge installer. The correct link is directly below this video. Check the Bridge factory installer heading and the address containing ir-bridge, slash install. Do not use the main firmware installer or the Companion installer. We are installing only the firmware for the separate IR Bridge.

  13. Bridge and RoonPilot have separate version numbers

    The release shown is IR Bridge 1.0.0 for RoonPilot 2.0.2. The different numbers are correct: these are separate firmware products. In future the page may show a newer Bridge version. What matters is using the correct Bridge installer and supported ESP32-S3 hardware.

  14. Check and confirm three items

    Scroll to the installation section. Read and confirm the three items covering hardware, full erase and the licence. Tick each box only when the statement actually applies. Connect and install Bridge then becomes available. This button first opens USB device selection. It does not immediately write the firmware.

  15. Select USB JTAG/serial debug unit

    Select USB JTAG slash serial debug unit for the ESP32-S3 Bridge board. Windows shows a COM number; macOS usually shows cu dot usbmodem. The number or suffix varies between computers. Click the correct row first, then Connect. With only the Bridge attached, you cannot confuse it with RoonPilot.

  16. USB serial is not the Bridge here

    If the entry only says USB serial, it is not the documented native ESP32-S3 port. Do not start an installation by guesswork. Disconnect the wrong device and connect the correct Bridge board. The open dialog updates its list. Unlike the round Waveshare device, reversing the Bridge connector does not select a second processor.

  17. Check the data cable, direct USB port and BOOT

    If no device appears, try a known data cable and a direct computer port without a hub. Unplug USB, hold BOOT on the Bridge and plug USB back in. Release BOOT when the native port appears. Also check that another program is not using the port. BOOT helps with installation; it is not the normal Bluetooth pairing procedure.

  18. Choose Install RoonPilot IR Bridge

    After connecting, the device dialog opens. Choose Install RoonPilot IR Bridge. The installation tool may use English labels even on the German webpage. That is normal. In the next step we explicitly select the full erase of the Bridge.

  19. Enable Erase device and choose Next

    Tick Erase device in the dialog and click Next. This prepares a full factory installation. An existing Bridge loses its old identity and setup. You do not need a separate erase beforehand. The separate RoonPilot device remains untouched, provided you selected the correct Bridge as shown.

  20. Install is the final start

    In the confirmation dialog, check the RoonPilot IR Bridge name and erase warning once more. Install now starts the actual process. Keep the USB cable connected, the browser open and the computer awake. Do not interrupt power or press BOOT during installation.

  21. Prepare → erase → write → finish

    The installer prepares the connection, erases flash storage and then writes the firmware. The percentage may increase at different speeds. Wait for the completion message, not just a single display of one hundred percent. This waiting period is shortened in the video. Installation may take longer on your computer.

  22. Installation complete – the Bridge starts

    Installation complete means the process has finished. Choose Next and close the dialog. The Bridge starts with a new RPB identity and slowly pulses blue. Leave it on stable USB power. Unlike RoonPilot, this IR Bridge does not open its own setup Wi-Fi. Continue on your RoonPilot webpage.

  23. Open the local RoonPilot webpage

    RoonPilot must already be configured for your home Wi-Fi and Roon. If not, follow the separate RoonPilot video guide first. Now open its local webpage using the known IP address and choose IR Bridge. Newer interfaces may call this simply Bridges. Keep RoonPilot and the Bridge close together for initial pairing.

  24. Enable Bridge & Bluetooth and restart

    If Bridge and Bluetooth is off, switch it on and choose Save and restart. Confirm the restart and wait for RoonPilot to become reachable again. Only then is Bluetooth actually running. An enabled switch without the required restart is not enough. Reopen the Bridge page afterwards. If Bluetooth is already active, you do not need to enable it again.

  25. Scan for Bridges – the identity matters

    Choose Scan for Bridges. Compare the complete RPB identity of your new Bridge with the discovered entry. The identity shown is only an example. Do not simply choose the strongest signal if several Bridges appear. Later, Identify Bridge can flash a brief blue signal to help you match the correct enclosure.

  26. Choose Pair this Bridge

    Choose Pair this Bridge beside the correct identity. Wait until the secure connection is ready. Successful pairing is confirmed by two brief blue LED flashes. Security should show an encrypted and bonded connection. A Bridge cannot belong to several RoonPilot devices at the same time.

  27. Ready via BLE – test the connection

    Check the saved Bridge and choose Test connection. This confirms communication between RoonPilot and the Bridge, not yet its effect on the amplifier. You can give the Bridge a useful display name. Its LED normally stays off during idle operation; that is intentional, not a fault.

  28. Set up Wi-Fi as another connection path

    For greater range you can allow Wi-Fi fallback. Select the intended Bridge using Manage and stay within Bluetooth range initially. RoonPilot sends its saved Wi-Fi credentials to the Bridge over the encrypted connection. Wait for the 2.4 gigahertz network connection and test the Wi-Fi path. Then return to zone control. No separate Bridge setup Wi-Fi or additional webpage is needed.

  29. IR profiles are your remote-control library

    An IR profile groups the commands for one piece of audio equipment. Open IR profiles and choose Create profile. Give it a unique name, such as Living Room Amplifier. This library is saved on RoonPilot. It is independent of which Bridge eventually sends the commands in each room.

  30. Start with 38 kHz and 33%

    Start with a carrier frequency of 38 kilohertz and a duty cycle of 33 percent. These suit many remotes. Duty cycle does not mean volume or the number of repeats. Change these values only when your equipment is known to require something different. Choose Save on RoonPilot. The new profile initially has no learned commands.

  31. Select the Bridge with an IR receiver

    Choose the saved profile and, under Learning Bridge, the paired Bridge that has an IR receiver. Click Start learning. Normal IR transmission is locked during this session. If you have several Bridges, one receiver is enough to learn all profiles. The Bridge used for transmission later can be a different one.

  32. First capture: point the original remote at the receiver

    Start with Volume down and choose Learn beside it. Wait for First recording. Point the original remote at the Bridge receiver from about ten to thirty centimetres away, not at the round RoonPilot display. Press the appropriate button as you normally would, then release it.

  33. Second capture: repeat the same button

    Wait for Second recording and press exactly the same remote button again. The Bridge compares both captures. On success the command is marked Captured and the LED confirms in green. If there is an error, repeat with the same button and better alignment. Do not press another button between the two captures.

  34. Five separate commands in the profile

    Also learn Volume up, Mute and, if needed, Power on and Power off. On and off deliberately have separate slots. If your remote uses the same button, learn it into both slots; this does not create genuine separate on and off codes. If switching off needs a held press, reproduce that behaviour. Later, enable only functions whose commands you actually learned.

  35. Save on RoonPilot finishes learning

    After recording, choose Save on RoonPilot. This is what commits the confirmed commands to the persistent library and ends the learning session. Discard keeps the previous library version instead. An unfinished session expires after at most ten minutes. Test the commands only after saving and completing the following zone assignment.

  36. Zone routing: choose the method, Bridge and profile

    Open Zone routing and find the intended Roon zone. Choose External IR Bridge, then the correct Bridge and learned profile. Click Save. RoonPilot automatically transfers and verifies the required profile copy before activating the route. Other zones can continue using normal Roon volume control. If the target Bridge is unreachable, a new route is not activated without verification.

  37. Start with 1x; enable optional buttons deliberately

    Set the knob step under Zone Management. Start with one times. Two times sends two IR volume commands per detent, not automatically two decibels. Enable Power and Mute separately for the zone, but only with the corresponding learned commands. A short tap on Power means on; a long press means off. Playback and pause remain Roon controls.

  38. First turn down and watch the audio equipment

    Pause playback and set a low level on the audio equipment. Select the assigned zone on RoonPilot and first turn down by just one detent. Watch the equipment: does its volume change? RoonPilot displays IR Volume with a relative step value. This is not a volume reading from the amplifier. Only then test volume up, mute and, carefully, optional power commands.

  39. The LED signals brief events

    Slow blue means the pairing window is open. Two brief blue flashes confirm pairing. Orange accompanies learning; two green flashes confirm a matching capture and two red flashes indicate a learning error. Violet is used during firmware updates: do not disconnect power then. During normal idle operation the LED is off. Read the ongoing connection status on the RoonPilot page.

  40. Check connection, profile and IR path separately

    If the equipment does not respond, first check the Bridge connection, selected zone, profile and transmitter alignment. A successful connection test does not prove IR reception. To re-pair a previously paired Bridge, deliberately power-cycle it three times within fifteen seconds. Then use its five-minute blue pairing window. This is not a routine restart procedure. Shared USB chargers can briefly interrupt other connected devices too.

  41. Up to four saved Bridges – explicit assignments

    RoonPilot can save up to four IR Bridges. Deliberately assign each zone its Bridge and profile. Manage selects a Bridge for configuration or maintenance; it does not simply change the route for your music zone. Return to zone control after maintenance. Start with one Bridge; you can add other transmitters later.

  42. Back up now; later updates without factory erase

    When everything works, create a new configuration backup under System and store the file privately on your computer. This saves profiles and routing. After a full erase, version 2.0.2 requires pairing again first, then restoring the appropriate profiles. Start future Bridge updates manually under Maintenance in RoonPilot. Routine application updates preserve setup; both devices must remain powered during them.

  43. Roon for music. The optional Bridge for IR.

    Your optional IR Bridge is now installed, paired and assigned to a zone. Roon still handles the music; the Bridge adds learned equipment commands. RoonPilot continues working without a Bridge.

Bridge Factory installer

Install the complete signed RoonPilot IR Bridge firmware directly from a desktop Chromium browser. No BIN download or command line is required.

Unannounced preview. This installer is deliberately not linked from the public RoonPilot pages. Use it only with the documented ESP32-S3-Zero-compatible Bridge hardware.
01

Factory means a complete erase

The installation removes the Bridge identity, BLE pairing, provisioned Wi-Fi fallback and every learned IR profile. Export a JSON profile backup from RoonPilot before reinstalling an existing Bridge.

No separate erase is needed. The installer requests and performs the required erase as part of this Factory operation.

02

Use a supported computer and port

Use a current desktop Chrome or Edge. Firefox, Safari, iPhone and iPad do not provide the Web Serial interface used here. Close Arduino Serial Monitor, ESP-IDF Monitor and every application using the Bridge port.

WindowsUSB JTAG/serial debug unit (COM…)
macOS / ChromeESP32-S3 or cu.usbmodem…

If the port does not appear, use a data-capable cable, hold the board’s BOOT button while inserting USB, then release BOOT once the native ESP32-S3 port is visible.

04

Continue in RoonPilot

After restart, the Bridge creates a new RPB-XXXX-XXX identity and slowly pulses blue. Open RoonPilot’s Bridge page, enable Bridge & Bluetooth, scan, compare the identity and confirm the encrypted pairing.

Continue with pairing
Normal future updates

Use RoonPilot’s Bridge → Bridge firmware update card. Updates are checked and installed through the encrypted Bridge connection; USB and erase are not required.

Installation policy

Update discovery may be automatic, but installation is always manual. Both RoonPilot and the Bridge verify the image before it becomes active.

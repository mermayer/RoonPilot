Bridge Factory installer

Install the complete signed RoonPilot IR Bridge firmware directly from a desktop Chromium browser. No BIN download or command line is required.

Official IR Bridge 1.0.0. Released together with RoonPilot 2.0.0. Use this installer only with the documented ESP32-S3-Zero-compatible Bridge hardware, not the RoonPilot display.
01

Factory means a complete erase

The installation removes the Bridge identity, BLE pairing, provisioned Wi-Fi fallback and every learned IR profile. Before reinstalling an existing Bridge, create a complete JSON backup under RoonPilot → System → Configuration backup. RoonPilot exports its stored profile library even when a Bridge is offline. After Factory installation, pair the new Bridge identity and explicitly select it as a target when restoring the named IR profiles. Signed application updates remain the simpler path for a healthy learned Bridge.

No separate erase is needed. The installer requests and performs the required erase as part of this Factory operation.

02

Use a supported computer and port

Use a current desktop Chrome or Edge. Firefox, Safari, iPhone and iPad do not provide the Web Serial interface used here. Close Arduino Serial Monitor, ESP-IDF Monitor and every application using the Bridge port.

Windows · in the Web InstallerUSB JTAG/serial debug unit (COM…)
macOS · in the Web InstallerUSB JTAG/serial debug unit (cu.usbmodem…)

The name before the parentheses is what matters. There is no need to inspect Device Manager or macOS System Information first. USB serial denotes a classic ESP32 in the chooser and is not the Bridge. If a wrong device is shown, leave the chooser open, disconnect USB and reconnect the intended device; the Web Installer lists it immediately. Keep only the Bridge connected by USB during this installation. If the port does not appear, use a data-capable cable, hold the board’s BOOT button while inserting USB, then release BOOT once the native ESP32-S3 port is visible.

03

Confirm, connect and install

Official release: version 1.0.0 · signed ESP32-S3 Factory image · 1,183,744 bytes. For an existing, paired Bridge, prefer the normal update through RoonPilot to retain its identity and profiles.

04

Continue in RoonPilot

After restart, the Bridge creates a new RPB-XXXX-XXX identity and slowly pulses blue. Open RoonPilot’s IR Bridge page, enable Bridge & Bluetooth, scan, compare the identity and confirm the encrypted pairing.

Continue with pairing
Normal future updates

Use RoonPilot’s IR Bridge → Bridge firmware update card. RoonPilot prefers authenticated Wi-Fi for transfer and can enable it temporarily through the bonded BLE link; USB and erase are not required.

Installation policy

Update discovery may be automatic, but installation is always manual. Both RoonPilot and the Bridge verify the image before it becomes active.

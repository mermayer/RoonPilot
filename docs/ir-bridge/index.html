A practical example

Keep RME Auto Ref Level where it belongs: inside the DAC.

For an RME ADI-2 DAC connected to a WiiM zone, RoonPilot can send the original RME infrared volume commands instead of changing Roon’s digital volume. The DAC therefore performs the level change itself and retains its Auto Ref Level behaviour.

  • Two learned 0.5 dB increments can form one precise 1.0 dB encoder step
  • Optional mute and separate short/long press power actions
  • No guessed absolute value is shown for an IR-only volume path
  • Native Roon control remains available for every other zone

02

Modern transport. Familiar infrared.

The Bridge stays simple at the equipment rack while RoonPilot manages setup, profiles, routing and updates.

Pair once

Every Factory installation creates a unique RPB-… identity. Select it in RoonPilot and confirm the first encrypted pairing on the round display.

Learn the original remote

RoonPilot guides the recording of volume, mute and separate power actions. Known protocols are analysed; unknown signals retain their raw timing.

Reach another room

BLE is preferred nearby. If enabled and BLE becomes unavailable, authenticated local Wi-Fi takes over automatically and returns control to BLE when it recovers.

Completely optional means completely off.

When Bridge & Bluetooth is disabled in RoonPilot, Bluetooth, scanning, Bridge update checks and all Bridge background work remain off after restart.

No cloud. No daemon. No extra computer.

Commands remain on the local network. The Bridge is a small hardware companion, not another service to maintain.

03

Compact hardware, clearly defined.

The target build uses a small ESP32-S3 board, an infrared receiver for learning and a dedicated transmitter for reliable range.

Controller
Compact ESP32-S3-Zero-compatible board · USB powered · no battery
IR receiver
AZ-Delivery KY-022-compatible receiver module · signal on GPIO5
Final transmitter
Adafruit High Power Infrared LED Emitter · product 5639 · signal on GPIO4
Prototype sender
AZ-Delivery IR transmitter module for short-range bench tests
Status light
Onboard RGB LED · blue pairing pulse and guided learning feedback
Firmware
ESP-IDF 6.0.1 · signed A/B OTA · persistent identity and profiles

The high-power transmitter is the intended final output stage. Its range and thermal behaviour will be validated with the production module before this extension is announced generally.

From bare board to a routed zone.

Initial USB installation is separate; everyday configuration then happens entirely through RoonPilot.

  1. 1

    Wire and inspect

    Connect the receiver, sender and a shared ground using the verified pin map.

  2. 2

  3. 3

    Enable Bridge & Bluetooth, start pairing and confirm the displayed RPB identity.

  4. 4

    Learn a profile

  5. 5

  6. 6

Understand Bridge updates

No unattended installation: RoonPilot may check for a new Bridge version and show a notice, but download and installation start only after explicit confirmation.

  1. 1
    RoonPilot validates

    HTTPS manifest, project, board, protocol, controller version, file size, embedded version and SHA-256 are checked first.

  2. 2
    Bridge validates again

    The Bridge verifies block order, size, SHA-256 and the RSA signature before selecting the inactive OTA partition.

  3. 3
    Version confirms success

    After restart, RoonPilot waits until the Bridge reconnects and reports the exact requested version.

Included in this build

  • Encrypted BLE pairing with persistent unique Bridge identity
  • Optional authenticated Wi-Fi fallback with BLE preference
  • Guided double-capture learning, NEC/Extended NEC analysis and lossless raw timing
  • Volume up/down, mute and separate Power on/off slots across up to eight profiles
  • Blue pairing, orange learning and green/red result feedback through the onboard RGB LED
  • Signed A/B update reception with SHA-256, embedded-version and RSA-3072 verification

Installation notes

This image is offered to a compatible, enabled RoonPilot Bridge only. RoonPilot validates the manifest and application before transfer; the Bridge validates it again before activating the inactive OTA partition. No installation begins without explicit confirmation.

The intended Adafruit 5639 high-power output stage still requires the final range, current and thermal acceptance test before a general Bridge announcement.

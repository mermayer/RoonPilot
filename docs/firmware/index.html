RoonPilot primary firmware

Firmware Installer

The primary ESP32-S3 firmware is installed only through this authorized browser installer. Factory and OTA images are not offered as standalone downloads.

Two independent processors. Verify the active chip before every write. The Web Installer targets only the ESP32-S3. Back up the complete original 16 MB ESP32-S3 flash and the separate 4 MB companion flash first. A Factory installation erases the complete ESP32-S3 and all of its settings.
ESP32-S3 only · USB Web Serial

Install in the browser

Use a current desktop Chromium browser such as Chrome or Edge. Close every serial monitor before continuing. Firefox and Safari do not support this Web Serial workflow.

macOS / Chrome: select the ESP32-S3

Choose USB JTAG/serial debug unit or the entry beginning with cu.usbmodem (USB VID 303A, PID 1001). Do not choose CH340, USB2.0-Serial, USB Serial or cu.wchusbserial; that is the companion ESP32. If only the companion appears, unplug USB-C, rotate the plug at the device by 180° and reconnect it.

Erase during a Factory installation

No separate erase is needed beforehand. When the installer offers Erase device, select or confirm it for a first installation or complete recovery. This clean install erases all ESP32-S3 settings, but it does not erase the companion ESP32. Later online updates under System → Firmware update do not require an erase.

Use a current desktop Chromium browser with Web Serial, for example Chrome or Edge. Open this HTTPS page before connecting the USB device.

Factory installation

Available only through the Web Installer above. It erases the ESP32-S3 before installing RoonPilot.

Normal updates

Installed directly by RoonPilot under System → Firmware update. No OTA file download is offered.

Separate classic ESP32 · optional

Companion Sleep firmware

This is the only separately downloadable RoonPilot firmware image. It releases shared signals, mutes the unused DAC path and puts the board's second ESP32 into deep sleep. A verified complete 4 MB backup is mandatory before installation.

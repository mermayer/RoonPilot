Firmware Installer

The primary ESP32-S3 firmware is installed only through this authorized browser installer. Factory and OTA images are not offered as standalone downloads.

Two independent processors. Check the name before the parentheses in the device chooser and select USB JTAG/serial debug unit for this installer. A Factory installation erases the complete ESP32-S3 and all of its settings. An original-firmware backup is optional and useful only if you may want to restore the exact manufacturer-delivered state later.
ESP32-S3 only · USB Web Serial

Install in the browser

Use a current desktop Chromium browser such as Chrome or Edge. Close every serial monitor before continuing. Firefox and Safari do not support this Web Serial workflow.

A clean return to version 1.0.2

This choice always installs the original RoonPilot 1.0.2, not the latest release or Waveshare's manufacturer firmware. It works over USB without needing RoonPilot's local website.

  • All settings and the profile library on RoonPilot are erased. Erasing is mandatory for this recovery. Set up Wi-Fi and Roon again after installation. The Companion processor and separate IR Bridges are not flashed.
  • Before upgrading from 1.0.2, keep a configuration backup made under 1.0.2. Do not import a 2.0.x backup into 1.0.2; keep it for a later return to 2.0.1.
  • The IR Bridge functions and extended group controls introduced in 2.0.0 are unavailable in 1.0.2.
  • Do not run battery calibration in 1.0.2. It does not include the calibration safety improvements added in 2.0.0.

Erase during a Factory installation

Erase is mandatory and performed automatically before flashing. There is no optional erase checkbox to leave unchecked. Save any configuration backup you need before continuing. This clean installation erases all settings and profiles on RoonPilot, including Wi-Fi and Bridge pairings. Set up Wi-Fi and Roon again afterward and pair your Bridges again. It does not flash the companion ESP32 or any separate Bridge.

Use a current desktop Chromium browser with Web Serial, for example Chrome or Edge. Open this HTTPS page before connecting the USB device.

Companion Sleep firmware

It releases shared signals, mutes the unused DAC path and puts the board's second ESP32 into deep sleep. RoonPilot also works fully without it.

The normal installation also needs no Python or command line and uses its own Web Installer. Select USB serial in the browser chooser, not USB JTAG/serial debug unit.

RoonPilot primary firmware

Firmware Installer

The primary ESP32-S3 firmware is installed only through this authorized browser installer. Factory and OTA images are not offered as standalone downloads.

Start with your operating system below. The USB name tells you whether the ESP32-S3 required by RoonPilot is connected. No command-line tool is needed.
ESP32-S3 only · USB Web Serial

Install in the browser

First identify the correct USB entry for your computer, then install in a current desktop Chrome or Edge browser.

Windows

Open Device Manager → Ports (COM & LPT).

✓ USB Serial Device (COMx)

Not this one: USB-SERIAL CH340 (COMx)

If CH340 appears, unplug USB, turn the USB-C plug at the device by 180 degrees and reconnect it.

Windows instructions →

macOS

Open System Information → Hardware → USB.

✓ USB JTAG/serial

Not this one: USB serial

If USB serial appears, unplug USB, turn the USB-C plug at the device by 180 degrees and reconnect it.

macOS instructions →

When asked, confirm Erase device. No separate erase is needed beforehand. Keep USB connected until installation is complete. This erases the ESP32-S3 settings, not the other processor.

Use a current desktop Chromium browser with Web Serial, for example Chrome or Edge. Open this HTTPS page before connecting the USB device.

Factory installation

Available only through the Web Installer above. It erases the ESP32-S3 before installing RoonPilot.

Normal updates

Installed directly by RoonPilot under System → Firmware update. No OTA file download is offered.

Optional second processor

Put the unused Companion ESP32 into deep sleep

RoonPilot works fully without this step. If you want the ESP32-U4WDH companion placed into a defined low-power state, use its own beginner-friendly Web Installer. No Python, Terminal or esptool is required for the normal Companion installation.

The separate page shows the correct Windows and macOS USB names and accepts classic ESP32 hardware only. The main installer above remains restricted to ESP32-S3 hardware.

# Internal IR Bridge OTA validation

This prerelease build exists only for controlled hardware validation of the
signed Bridge online-update path. It is not a public RoonPilot IR Bridge
release and must not be linked from the project website, installer,
documentation, or stable update channel.

Test.43 is functionally identical to the hardware-proven Test.42 application.
Its new version number exists solely to validate simultaneous Controller and
Bridge update availability, compatibility checks, ordered installation and
reconnection on the real paired devices.
